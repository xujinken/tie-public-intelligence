# 硬科技外视角 · Hardtech Outside View

> **站在企业外面看硬科技** | 同一个信息，不同视角

企业内部的团队很优秀。但每个人都被自己的角色定义了视野：CTO 看技术路线，销售 VP 看客户反馈，创始人看融资和产品。这不是能力问题，是位置问题。

我们站在企业外面，用一套聚焦产业链物理层瓶颈的分析框架，持续追踪那些"不在任何人的日常 KPI 里、但可能影响下一步决策"的外部信号。

---

## 为什么做这个

硬科技产业的决策者每天被新闻淹没。但真正值得关注的变化，往往不在头条里：

- 某家供应商的交期从 8 周拉长到 26 周——表面是涨价，实际瓶颈可能在别处
- 三家互不相关的传感器厂同时涨价 15%——是巧合，还是产业链上游有结构性变化？
- 全球 Top 5 供应商中没有一家中国公司——国产替代的窗口什么时候打开？

我们把这些分散的公开信号**拼接成可行动的产业洞察**。

---

## 方法论

每份报告基于三个层级交叉验证：

| 层级 | 来源 | 回答什么问题 |
|------|------|-------------|
| **物理层** | 产品 BOM 拆解、技术规格书、专利 | 这东西到底由什么组成？瓶颈在哪个工序？ |
| **供应链层** | 供应商财报、行业报告、交期数据 | 谁控制着关键环节？产能卡在哪里？ |
| **信号层** | 招聘变动、融资事件、政策文件、会议议程 | 正在发生什么变化？ |
