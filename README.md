# TIE Public Intelligence

> **硬科技产业链公开情报** | 基于公开信息的产业瓶颈与结构性变化观察

TIE（Target Intelligence Engine）追踪硬科技产业链中被忽视的关键瓶颈——那些"缺了它整条链就停摆"的环节。我们只使用公开信息，不涉及企业内部数据。

## 为什么做这个

硬科技产业的决策者每天被新闻淹没，但真正值得关注的信号往往藏在噪音里：

- 某家供应商的交期从8周拉长到26周——这意味着什么？
- 三家互不相关的传感器厂同时涨价15%——这是巧合还是趋势？
- 全球Top 5供应商中没有一家中国公司——国产替代的窗口什么时候打开？

TIE Public Intelligence 将这些分散的公开信号**拼接成可行动的产业洞察**。

---

## 方法论

每份报告基于三个信息源交叉验证：

| 层级 | 来源 | 回答什么问题 |
|------|------|-------------|
| **物理层** | 产品BOM拆解、技术规格书、专利 | 这东西到底由什么组成？ |
| **供应链层** | 供应商财报、行业报告、交期数据 | 谁控制着关键环节？ |
| **信号层** | 招聘变动、融资事件、政策文件、会议议程 | 正在发生什么变化？ |

所有结论均可追溯至公开来源。我们不做投资建议。
