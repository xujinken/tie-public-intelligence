# 智元冲港股：人形机器人从"谁造得多"到"谁玩得转资本"

> **硬科技外视角 | 2026-08-01**
> 本文仅基于公开信息整理，不构成投资建议。所有主张的来源层级见文末附录。

---

## 发生了什么

2026年7月24日，智元机器人（Agibot）正式启动赴港上市流程。中金、中信证券、摩根士丹利三家联席保荐。[^1]

这不是人形机器人赛道的第一次IPO——优必选2023年已登陆港股，宇树科技2026年7月2日科创板注册生效——但智元的上市，可能是这个赛道最具差异化的资本实验。

智元2023年2月才成立。两年半做到10亿营收、全球出货量第一、冲击400-500亿港元估值。[^2] 速度本身不是故事。故事在于它的架构设计——"1+5+N"——这在人形机器人行业几乎没有先例。

---

## "1+5+N"是什么？

这不是公司官方命名的架构，而是行业分析对其组织模式的总结。理解它的最好方式是看结构：[^3]

```
                    智元创新（港股IPO母体）
                    人形整机 + 具身大模型 + OS
                    ┌───┬───┬───┬───┐
                临界点   酷拓   觅蜂  擎天租  智鼎
                (灵巧手) (四足) (数据) (RaaS) (清洁)
                 │       │      │      │      │
                 ▼       ▼      ▼      ▼      ▼
              对内配套  独立融资  单独估值  独立股权激励
```

**五家子公司各有独立的赛道估值逻辑**：灵巧手（临界点）可以卖给行业对手、数据服务（觅蜂）可以供给整个生态、机器人租赁（擎天租）是SaaS式的经常性收入。

如果只把智元当成一家"人形机器人整机公司"，就会错过这个结构设计最重要的意图：**它不是在造机器人，它在造一个可以向外输出零部件、数据、租赁服务的产业基础设施平台。**

---

## 为什么港股？

智元选港股而非A股，有三个现实考量：

**1. 港股18C制度**。允许未盈利硬科技公司上市。智元2023-2025年累计净亏损约2.8亿元[^3]，不满足A股主板盈利要求。港股18C专为这类公司设计。

**2. 港/A双资本通道**。智元已经通过控股上纬新材（科创板A股上市公司）拥有了一个A股平行上市载体。[^4] 如果港股IPO成功，智元将成为人形机器人赛道唯一同时拥有港/A双资本平台的公司。

**3. 海外机构投资人**。港股聚集了更熟悉"亏损硬科技+平台故事"定价逻辑的国际投资者。这个群体比A股投资者更愿意为"平台生态"付费——因为他们见过太多"硬件+平台"双轮驱动的先例。

## 与宇树的路线分化

把智元和宇树放在一起看，商业模式的分化格外清晰：[^5]

| | 智元机器人 | 宇树科技 |
|------|-----------|---------|
| 核心路线 | 平台生态（1+5+N） | 运动控制硬件 |
| 2025年营收 | 10.5亿元 | 17.08亿元 |
| 2025年出货量 | 5168台（Omdia） | >5500台（公司声明）* |
| 核心优势 | 全产业链闭环 + 母子分层资本架构 | 硬件自研率>90% + 连续五年盈利 |
| 短板 | 战线极宽，资金消耗巨大 | 缺少独立数据/灵巧手/RaaS板块 |
| 上市地 | 港股 + A股平行 | 科创板 |
| 估值 | 400-500亿HKD（投资人预期） | ~420亿RMB（发行市值） |

*\*注：Omdia 2025年出货量排名存在争议。Omdia报告称智元5168台第一、宇树4200台第二。宇树于2026年1月22日公开声明其2025年实际出货>5500台，质疑Omdia方法论。[^6]*

对比揭示了一个根本性选择：**是像宇树那样把硬件做到极致、用盈利能力证明价值？还是像智元那样把生态铺开、用平台想象说服市场？**

两种路线各有利弊。宇树的优势是现金流——2025年利润预计1-2亿元[^5]，在人形机器人行业极为罕见。智元的优势是生态位——如果具身智能真的成为"下一代海量智能终端"，提前卡位产业链每个关键节点的公司，将拥有远超单一人形整机厂商的定价权。

但智元的风险也同样明显。邓泰华本人在4月合作伙伴大会上透露"即便无任何营收，现有现金流也能支撑三年"[^7]——这意味着智元对资本市场持续输血的需求远高于宇树。如果IPO窗口提前关闭或者二级市场对亏损平台公司的耐心耗尽，智元的战线宽度将从优势变为软肋。

---

## 这对行业意味着什么

**上市潮已来。** 宇树科创板 + 智元港股 + 优必选港股 + 十余家股改/辅导中。从一级市场估值到二级市场定价的转换正在发生。与两年前不同，现在上市的不再是"PPT公司"——智元2025年出货5168台、2026年Q1已突破1万台。[^2]

**资本市场的定价逻辑正在分化。** 宇树的PS约24倍（2025年营收），智元若按400亿HKD估值约32倍PS。[^2] 市场在给"平台生态"支付溢价。但这个溢价能维持多久？

一个值得追踪的信号是：Omdia vs 宇树的出货量排名争议，本质上是"谁是世界第一"的叙事之战。在IPO定价的关键窗口期，"第一"和"第二"的市场认知差异，直接转化为估值差异。这不是无关紧要的数据细节，而是资本竞争的一部分。

**TIE此前两周的发现为这个趋势提供了上下文**：传感器交期26周+涨价15%（7/27报告）、近20家车企跨界造人（7/28报告）——这些信号都指向同一个方向：人形机器人的上游供应链正在重构，而智元的"1+5+N"架构本质上是押注"谁控制供应链关键节点，谁就掌握定价权"。
